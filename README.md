# Мурино Pixel

Браузерная градостроительная игра «Мурино».

## Публикация через GitHub Pages

1. Загрузите файл `index.html` из архива релиза в корень репозитория.
2. Откройте **Settings → Pages**.
3. В разделе **Build and deployment** выберите **Deploy from a branch**.
4. Выберите ветку `main` и папку `/(root)`, затем нажмите **Save**.

После публикации игра будет доступна по адресу:
https://ilyechenok.github.io/murino-city/

## Сохранение города

В версии 4.6 добавлены кнопки **Экспорт** и **Импорт** в верхней панели.
Перед переходом на сайт откройте прежнюю версию игры, нажмите **Экспорт** и сохраните JSON-файл города.
После публикации сайта откройте его, нажмите **Импорт** и выберите сохранённый JSON-файл.
Дальше игра будет сохраняться в браузере на том же сайте и устройстве.

Не удаляйте JSON-файл экспорта, пока не убедитесь, что город успешно импортирован.
