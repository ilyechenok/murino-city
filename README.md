# Мурино Pixel

Браузерная градостроительная игра «Мурино».

## Публикация через GitHub Pages

1. Загрузите `index.html` из версии 4.6 в корень репозитория.
2. Откройте **Settings → Pages**.
3. В разделе **Build and deployment** выберите **Deploy from a branch**.
4. Выберите ветку `main` и папку `/(root)`, затем нажмите **Save**.

После публикации игра будет доступна по адресу:
https://ilyechenok.github.io/murino-city/

## Сохранение города

В версии 4.6 есть кнопки **Экспорт** и **Импорт** в верхней панели.
Сначала откройте версию 4.6 в том же браузере. Она попробует подхватить сохранение версии 4.5, если браузер предоставляет ей доступ к прежнему локальному хранилищу.
Если город загрузился, нажмите **Экспорт** и сохраните JSON-файл.
После публикации сайта откройте его, нажмите **Импорт** и выберите JSON-файл.
Дальше игра будет автоматически сохраняться в браузере на этом сайте и устройстве.

Не удаляйте JSON-файл экспорта, пока не убедитесь, что город успешно импортирован.
